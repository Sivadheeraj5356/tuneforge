Take this experiment to compute.
NO SERVER-SIDE TRAINING
The hosted workbench plans and validates. Actual training runs in your own Python environment or a free Colab GPU when available. This site does not provision compute or charge your account.
1. Get the toolkit
git clone https://github.com/Sivadheeraj5356/tuneforge.git
cd tuneforge
python -m pip install -e '.[dev]'
The repository is private. Sign in with an account that has access before cloning.
2. CPU demonstration, no model download
python examples/cpu_demo.py
Tiny randomly initialized model, eight synthetic rows and two training steps. Verifies train → adapter → generation → merge, not model quality.
3. Your real experiment, CUDA GPU required
Download the YAML, place your validated dataset beside it as training.jsonl, then run:
tuneforge train --config tuneforge.yaml
